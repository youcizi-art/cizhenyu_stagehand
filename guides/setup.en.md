# Stagehand setup

1. **Run mode**: Auto (default) prefers a local browser, then cloud; or force Local only / Cloud only.
2. **Model provider**: Selecting a provider prefills model name and compatible endpoint; you can edit them.
3. **Model API Key**: Required for the Stagehand process (independent of Agent quotas).
4. **Browserbase** (recommended): Copy API Key and Project ID from [Browserbase Settings](https://www.browserbase.com/settings). Required for Cloud-only mode.
5. Install and enable Stagehand (Node ≥ 20). After source changes, use Toolbox → Update / reinstall.

More model notes: [Stagehand Models](https://docs.stagehand.dev/v3/configuration/models).
